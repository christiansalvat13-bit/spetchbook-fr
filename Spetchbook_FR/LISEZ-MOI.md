# Spetchbook en français (traduction non officielle)

Application d'origine : Spetchbook, par notebysebas — https://notebysebas.github.io/spetchpad
Licence : Polyform Noncommercial 1.0.0 (voir LICENSE.txt). Usage personnel et non commercial uniquement.

## Ce qui a été modifié (2026-10-16)
- Ajout d'un module de traduction à la fin de `index.html` : il traduit à l'affichage les menus,
  boutons, infobulles, messages et étiquettes du cube de navigation. La logique de l'appli n'est pas touchée.
- `traduction_fr.js` = copie lisible du même module (le dictionnaire anglais → français), pour corriger un mot si besoin.
- Nom de l'appli sur l'écran d'accueil : « Spetchbook FR ».

## Vocabulaire
- Loft = surface tendue entre plusieurs traits (terme gardé tel quel, abrégé « Lft »).
- Ext = extrusion ; Sld = solide ; Réf = objets de référence (cube, sphère…).
- Manipulateur = les poignées pour déplacer/pivoter/redimensionner (« gizmo »).
- Magnétisme = accroche par crans ; 1D / 2D = un doigt / deux doigts ; 1P = 1re personne.
- LCL / WLD (local / monde), NAV, ORTHO, PERSP : abréviations laissées en l'état.

## Pour l'utiliser sur l'iPad
Ces fichiers doivent être hébergés sur un site web (ex. GitHub Pages, gratuit), puis ouverts dans Safari
→ Partager → « Sur l'écran d'accueil ».

## Mise à jour
Si l'auteur publie une nouvelle version, il faut retélécharger son index.html et y réinsérer le module
(demander à Claude : « remets la traduction française sur la nouvelle version de Spetchbook »).
